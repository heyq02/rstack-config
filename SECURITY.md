# Security Policy

## Supported versions

Security fixes are applied to the latest published release of `@heyq02/rstack-config` on npm.

## Reporting a vulnerability

Please **do not** open a public issue for security reports.

Email the maintainer at [mail@heyq02.cn](mailto:mail@heyq02.cn) with:

- A description of the issue
- Steps to reproduce or a proof of concept when possible
- Impact assessment if known

You should receive an acknowledgement within a few days. After a fix is available we will coordinate disclosure.
